# SDA Academy — Sobia Digital Academy

A premium, responsive one-page website for **SDA Academy**, focused on practical digital skills, live Google Meet learning, AI tools and student support.

## Features

- Premium blue / navy / gold visual system
- Responsive sticky navigation with mobile menu
- Hero section with local SDA digital-learning illustration
- One featured course: Canva AI Course
- Live Google Meet classes section
- Why SDA feature cards
- 4-step learning journey
- 22 interactive sample/demo testimonials
- Touch-friendly testimonial carousel with auto-slide
- About SDA section
- CTA and contact sections
- Floating WhatsApp button
- Back-to-top control
- Page loader
- Scroll-reveal animations
- Reduced-motion support
- Semantic HTML and accessible controls
- No backend required
- GitHub Pages compatible
- No YouTube links, embeds or icons

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Local SVG visual assets
- Optional Google Fonts (Inter)

## Run locally

No build step is required. Open `index.html` in a browser, or serve the folder with any static file server.

## Deploy to GitHub Pages

1. Push the project to a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)`.
5. Save and wait for the Pages workflow to finish.

The project uses relative asset paths, so it works from a GitHub Pages project URL.
